# 从文字制作音频

入口：音频库的“添加音频” → “从文字制作音频”，或登录后打开 `/studio.html`。

## 使用流程

1. **准备正文**：粘贴整理好的朗读稿，去掉不需要读出的网址、批注、表格。选择约 800、1,000 或 1,200 字一段，预览后保存。优先沿自然段和句末切分，超长单句按长度切开；保存后的分段拼回去就是完整正文。未提交输入暂存在当前浏览器，提交后的任务保存在云端。
2. **固定声音**：默认 Charon 和平静自然的中文朗读要求。每篇任务固定正文、声音名称和朗读要求，避免中途混用版本。正文或声音需要更改时，创建新任务。
3. **逐段生成**：复制朗读要求到 [Google AI Studio 语音生成](https://aistudio.google.com/generate-speech)的 Style，选择同名声音，再复制该段正文到 Text，生成后下载音频。这里不读取 Google 登录、不调用 Gemini API、不创建付费项目。免费额度由 Google 账号决定，用完可稍后继续。
4. **上传检查**：把下载文件上传到相应分段。工具完整解码，检查时长、长静音、同一任务内重复音频，并保存可播放的统一格式。时长与字数只作粗略提示，不能证明内容准确。
5. **试听核对**：核对开头、末尾、漏读、重读以及声音一致性。第二段起可直接听上一段最后 15 秒，再听本段。确认后勾选“已试听核对”。不满意时重新生成并上传这一段；新文件检查成功才替换旧文件，替换后需要重新核对。
6. **合并入库**：全部段落核对完成后，一键按顺序合并成 MP3，调整整体音量并加入音频库。合并在服务器继续执行，可以关闭网页。重复点击/重试不会重复入库。

声音生成保留免费网页步骤：复制 → 生成 → 下载 → 上传。没有无人值守生成，也没有自动转写或逐字比对。不要把“文件检查通过”理解为“正文完全正确”。分段生成可能发生声线漂移；固定声音和提示能减少变化，对照试听和单段重做负责最后把关。合并的音量处理不能修复声线变化。

## 保存、重做与清理

- 保存后的分段、上传文件、核对状态在云端保留，刷新、换设备或服务重启后可继续。
- 多页面操作通过版本检查避免旧进度覆盖新进度。冲突时重新载入云端进度再操作。
- 上传期间请保持页面打开；若网络中断，刷新查看是否已保存，必要时只重传该段。
- 合并失败保留分段并允许重试。服务重启会将中断的合并标记为可重试，不把残缺文件当成成功。
- 已入库任务不再替换分段。若最终音频从库中删除，可用仍保留的草稿重新合并。
- 删除制作草稿会删除正文记录和分段文件，**不会删除已入库音频**；删除音频库条目也不会删除制作草稿。两者分别管理空间，无回收站。
- 默认最多 50 个任务；每篇最多 100,000 字；每段音频最多 100 MB、20 分钟；每个任务的解码后分段文件最多 1 GB。所有任务一次处理一个上传或合并，避免占满服务器。
- 全部制作接口和分段试听仅限库主人访问；分享访客不能查看正文、草稿或制作工作台。

## 运维与接口

需要 `ffmpeg` 和 `ffprobe` 位于服务进程 PATH。音频处理不使用 shell、不接受网络来源、拒绝播放列表输入；临时文件和分段文件保存在 `DATA_DIR/studio/任务ID/`，最终 MP3 在 `UPLOAD_DIR`。新表 `studio_projects`、`studio_segments` 为增量创建，不更改已有音频、登录、分享或续听表结构。备份整个数据目录、数据库和音频目录。

| 路径 | 用途 |
| --- | --- |
| `GET /api/studio/config` | 默认朗读要求、限制和音频组件状态 |
| `POST /api/studio/preview` | `text`、`target` 分段预览，不保存 |
| `GET/POST /api/studio/projects` | 列出/新建任务；创建需客户端 UUID `id`，供断网重试去重 |
| `GET/DELETE /api/studio/projects/:id` | 查看/删除草稿；删除需当前 `revision` |
| `PATCH /api/studio/projects/:id/segments/:index` | 保存 `copied: true` 或 `reviewed: boolean`，需当前 `revision` |
| `POST /api/studio/projects/:id/segments/:index/audio` | 单个 `audio` 文件；`X-JTG-Revision` 头用于版本检查 |
| `GET /api/studio/projects/:id/segments/:index/audio` | 私人分段试听，支持 Range |
| `POST /api/studio/projects/:id/merge` | 当前 `revision` 发起合并，202 后轮询任务；已成功则返回同一音频 |

沿用现有登录和写请求保护（`X-JTG-Request: 1`）；正文 JSON 上限 1 MB，验证登录后才读取。所有路径均为同源，不向 Gemini 传输任何内容，只有用户在 Google 网页粘贴后才提交给 Google。
