# 从文字制作音频

入口：音频库的“添加音频” → “从文字制作音频”，或登录后打开 `/studio.html`。

## 使用流程

1. **准备正文**：粘贴整理好的朗读稿，去掉不需要读出的网址、批注、表格。选择约 800、1,000 或 1,200 字一段，预览后保存。优先沿自然段和句末切分，超长单句按长度切开；保存后的分段拼回去就是完整正文。未提交输入暂存在当前浏览器，提交后的任务保存在云端。
2. **固定声音**：默认 Charon 和平静自然的中文朗读要求。每篇任务固定正文、声音名称和朗读要求，避免中途混用版本。正文或声音需要更改时，创建新任务。
3. **连接并生成**：在 [Google AI Studio](https://aistudio.google.com/api-keys) 获取未启用结算的免费项目 API Key，在工作台点“连接 Gemini”，确认免费项目后检查连接。点击“自动生成未完成分段”，浏览器逐段调用官方接口，再将声音自动保存到工作台。生成时保持页面打开；额度不足或网络出错会暂停，之后只继续缺少音频的分段。不满意的分段可单独重做。
4. **文件检查**：自动保存和手动上传都经过相同检查。工具完整解码，检查时长、长静音、同一任务内重复音频，并保存可播放的统一格式。时长与字数只作粗略提示，不能证明内容准确。
5. **试听核对**：核对开头、末尾、漏读、重读以及声音一致性。第二段起可直接听上一段最后 15 秒，再听本段。确认后勾选“已试听核对”。不满意时重新生成并上传这一段；新文件检查成功才替换旧文件，替换后需要重新核对。
6. **合并入库**：全部段落核对完成后，一键按顺序合并成 MP3，调整整体音量并加入音频库。合并在服务器继续执行，可以关闭网页。重复点击/重试不会重复入库。

每段长度和声音菜单统一在字段下方展开；支持上下方向键、回车选择、Esc 取消和 Tab 切换。窄屏下优先在窗口内腾出下方空间，菜单本身可滚动；系统设置减少动态效果时关闭展开动画。

没有 API Key 时，可继续走免费网页：复制朗读要求到 [Google AI Studio 语音生成](https://aistudio.google.com/generate-speech)的 Style，选择同名声音，将本段正文放入 Text，生成后下载并上传到对应段落。网页免费额度与 API 额度独立。工具没有自动转写或逐字比对。不要把“文件检查通过”理解为“正文完全正确”。分段生成可能发生声线漂移；固定声音和提示能减少变化，对照试听和单段重做负责最后把关。合并的音量处理不能修复声线变化。

## 免费项目与密钥

- 当前固定使用 `gemini-3.8-flash-tts`，同一任务沿用声音和朗读要求，正文与风格指令分开提交。不会自动重试语音生成或切换到其他模型；HTTP 429 后暂停。[官方语音文档](https://ai.google.dev/gemini-api/docs/speech-generation)。
- 官方提供免费层，但 API Key 继承项目的计费状态，工具无法从密钥核实账单。必须选未启用结算的免费项目，并在连接时明确确认。以后不要给此项目开启结算；连接成功只代表能访问模型，不证明账单状态。[价格](https://ai.google.dev/gemini-api/docs/pricing)、[计费说明](https://ai.google.dev/gemini-api/docs/billing)。
- 工具保守地限制相邻请求至少间隔 65 秒、所有任务过去 24 小时内最多 20 次生成尝试。这是工具保护上限，并非 Google 保证的免费额度；失败的尝试也计入。Google 的项目配额可能更低，并会调整；以 AI Studio 显示为准。达到限制后保留进度，稍后手动继续。
- Key 默认只保留在当前页面内存。主动勾选“在这台设备上记住连接”，才保存到当前网站的浏览器本地存储（localStorage），刷新、关闭标签页后重新打开都可恢复；仅限同一设备、浏览器用户配置及网站地址，不经过 JTG 服务器、数据库或日志，也不由本应用跨设备同步。只有自己的设备适合勾选；清理网站数据或使用无痕窗口后可能需要重填。
- 连接设置可留空密钥以沿用当前连接。取消勾选并保存，会删除设备保存的密钥，只保留当前页连接；“断开并清除此设备的密钥”同时清除新版设备存储与旧版标签页存储。已打开的新版工作台通过浏览器事件同步清除，并停止继续生成下一段；不会撤销 Google 侧的密钥，也不会删除制作进度。旧版标签页保存不会自动升级为长期保存。
- 浏览器直接向 Google 官方接口发送正文和朗读要求，必须能直接访问 Google；JTG 服务器只接收音频与制作进度，不代理请求、不读取 Google 登录。免费服务的数据使用遵循 Google 条款。请求使用 `store: false` 关闭 Interactions 对话状态存储，这不等于关闭免费层的数据使用。

## 保存、重做与清理

- 保存后的分段、上传文件、核对状态在云端保留，刷新、换设备或服务重启后可继续。
- 多页面操作通过版本检查避免旧进度覆盖新进度。冲突时重新载入云端进度再操作。
- 自动生成和上传期间保持页面打开；点击“暂停生成”会等当前段保存完成后停下。关闭页面、电脑休眠或后台限制可能中断，已保存段落保留；在途结果不保证能找回。
- 生成成功但保存失败时，浏览器先重传同一份音频，避免重复占用生成额度。仍失败会保留当前页内存中的文件，可“重试保存本段”或下载备份；此时不要关闭或刷新页面。
- 合并失败保留分段并允许重试。服务重启会将中断的合并标记为可重试，不把残缺文件当成成功。
- 已入库任务不再替换分段。若最终音频从库中删除，可用仍保留的草稿重新合并。
- 删除制作草稿会删除正文记录和分段文件，**不会删除已入库音频**；删除音频库条目也不会删除制作草稿。两者分别管理空间，无回收站。
- 默认最多 50 个任务；每篇最多 100,000 字；每段音频最多 100 MB、20 分钟；每个任务的解码后分段文件最多 1 GB。所有任务一次处理一个上传或合并，避免占满服务器。
- 全部制作接口和分段试听仅限库主人访问；分享访客不能查看正文、草稿或制作工作台。

## 运维与接口

需要 `ffmpeg` 和 `ffprobe` 位于服务进程 PATH。音频处理不使用 shell、不接受网络来源、拒绝播放列表输入；临时文件和分段文件保存在 `DATA_DIR/studio/任务ID/`，最终 MP3 在 `UPLOAD_DIR`。表 `studio_projects`、`studio_segments`、`studio_generation`、`studio_generation_attempts` 为增量创建，不更改已有音频、登录、分享或续听表结构。备份整个数据目录、数据库和音频目录。

| 路径 | 用途 |
| --- | --- |
| `GET /api/studio/config` | 默认朗读要求、限制和音频组件状态 |
| `POST /api/studio/preview` | `text`、`target` 分段预览，不保存 |
| `GET/POST /api/studio/projects` | 列出/新建任务；创建需客户端 UUID `id`，供断网重试去重 |
| `GET/DELETE /api/studio/projects/:id` | 查看/删除草稿；删除需当前 `revision` |
| `PATCH /api/studio/projects/:id/segments/:index` | 保存 `copied: true` 或 `reviewed: boolean`，需当前 `revision` |
| `POST /api/studio/projects/:id/segments/:index/audio` | 单个 `audio` 文件；`X-JTG-Revision` 头用于版本检查 |
| `GET /api/studio/projects/:id/segments/:index/audio` | 私人分段试听，支持 Range |
| `POST /api/studio/projects/:id/generation` | 当前 `revision`、客户端 UUID `runId`/`token`、`mode: missing/single` 开始一轮；单段重做需 `index` 及 `replace: true` |
| `POST /api/studio/projects/:id/generation/heartbeat` | `X-JTG-Generation` 续期，浏览器每 20 秒请求；90 秒断开后暂停 |
| `POST /api/studio/projects/:id/generation/next` | 同一运行令牌领取一个待生成分段或等待时间，领取即记一次尝试 |
| `POST /api/studio/projects/:id/generation/pause` | 同一运行令牌暂停；其他页面需当前 `revision` 才能停止 |
| `POST /api/studio/projects/:id/merge` | 当前 `revision` 发起合并，202 后轮询任务；已成功则返回同一音频 |

沿用现有登录和写请求保护（`X-JTG-Request: 1`）；正文 JSON 上限 1 MB，验证登录后才读取。JTG 制作接口为同源；自动生成另从浏览器直连 `generativelanguage.googleapis.com`，只在该请求头传递 Gemini Key。生成运行令牌是独立随机值，数据库只存散列，不能代替 Gemini Key。自动上传同时带版本和运行令牌；全库只允许一个自动生成任务，处理中禁止修改同一任务。服务重启会暂停旧运行。Google 请求超时不证明对方未处理，不自动再次生成；保存回执丢失时先检查同一运行的已保存记录。
